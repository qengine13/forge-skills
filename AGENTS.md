# Working on Forge Skills

Preserve the behaviour contracts and source attribution. Keep examples fictional and self-contained.
Never publish local credentials, project memories, session transcripts, or private configuration.
Do not modify any external source collection while editing this public edition.

Read docs/release/preflight.md before changing scope. Model names belong in runtime discovery,
not fixed routing tables. Respect the user's subscription and explicit model choices.

Run `python3 -m unittest discover -s tests -v` and the package validation before publishing.
Report structural checks, behaviour evaluation, hosted checks, and public access separately.
Use independent scenario evaluation when changing skill behaviour; pass raw tasks, not desired answers.
