A skill is a reusable set of instructions for your AI assistant. These two help it check a plan before starting, and find useful decisions you have chosen to save.

01 / Plan Hygiene

Great idea. Better plan.

What it helps with

You ask for a booking page. Before building, the assistant checks what already exists, what might go wrong, and how you will know the result works.

After installation, try saying

“Use Plan Hygiene to check my booking-page plan. Don’t build it yet.”

Other installed skills can help when your project’s rules call for them. They do not all run automatically.

02 / Agent Memory

“I already told you that.”

What it helps with

Your shop offers collection only. Save that decision explicitly, then ask the assistant to find it in a later session. It should still check whether the decision applies today.

Download wide video · Vertical video
After connecting the memory tool, try saying

“Remember: we only offer collection. Check this before changing our shop page.”

Later: “What did we decide about collection?” Saving requires your permission.

Start with one skill.

  1. Choose your assistant. The collection is designed for Claude Code and Codex working with your project files. Installing it does not add features to every ordinary chat app.
  2. Follow the setup guide. It explains how to copy a skill into your project. Agent Memory also needs a one-time connection to its local storage tool.
  3. Ask in plain English. Use one of the examples above. Read the findings and decide the next action.
